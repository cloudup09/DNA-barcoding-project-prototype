How the Algorithm Works

  1. The DNA sequence is checked to ensure that it contains only A, T, C and G.
  2. Each base is assigned a 2-bit binary value according to the selected mapping.
  3. The binary values are converted into colored blocks to create a digital DNA barcode.
  4. The generated barcode is compared with the simulator's reference database.
  5. The verification result reports the closest matching reference sequence.
